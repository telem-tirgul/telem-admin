תלם שלי – אפליקציית דפי התרגול של תלם
=====================================

מה יש בתיקייה
- CHANGES.txt – מה השתנה בכל גרסה.
- index.html – האפליקציה (צד תלמיד + מסך ניהול למנהלת).
- manifest.webmanifest, sw.js, icon-*.png, logo.png – מה שמאפשר "הוספה למסך הבית".

התקנה / עדכון
1. קובצי SQL (בתיקייה 1-sql שליד התיקייה הזו) – להריץ ב-Supabase רק את מה שעוד לא הורץ:
   72.1 (אפליקציה; הורץ בשם 63.1), 73.1 (שכחתי את הקוד).
2. GitHub, חשבון telem-tirgul, ריפו students (Public).
3. להעלות לריפו את כל הקבצים מהתיקייה הזו (בלי התיקייה עצמה).
   עדכון לגרסה חדשה: באותו ריפו > Add file > Upload files > לגרור את כל הקבצים (הם מחליפים את הישנים) > Commit changes.
4. פעם ראשונה בלבד: Settings > Pages > Branch: main > Save.
5. הכתובת: https://telem-tirgul.github.io/students/

כניסה
- מנהלת: "כניסת צוות" למטה, עם האימייל והסיסמה של מערכת הניהול.
- תלמיד/ה: טלפון + קוד. יוצרים חשבון במסך הניהול > תלמידים > שם התלמיד/ה > "יצירת חשבון ושליחת קוד".
